Projects
AI-Powered Cognitive Accessibility Tool (Chrome Extension)
I built a Chrome extension to enhance web accessibility for users with
cognitive disabilities like dyslexia and ADHD. The tool's core innovation
is its use of Chrome's Built-in AI (Gemini Nano) to perform complex,
on-device text adaptation. By leveraging the Prompt API, I architected a
100% privacy-first system that works entirely offline, ensuring no user
data leaves the browser. I developed sophisticated prompts for AI-driven
features like "Simplify Complex Ideas" and "Better Visual Organization,"
demonstrating the capability of local LLMs to handle sensitive
accessibility tasks by restructuring content to reduce cognitive load
while preserving its original meaning.
On-Device AI Knowledge Graph & Search
I developed a privacy-first web application that transforms a user's
browsing history into an interactive, visual knowledge graph. I
architected a 100% in-browser AI system using Gemini Nano for
on-device content summarization and AI-powered filtering. A core
technical challenge involved advanced prompt engineering to optimize
summarization performance on the resource-constrained local LLM. To
enable powerful semantic search and guarantee data privacy, I integrated
pglite and pgvector to create a local-first vector database, allowing all
data storage, retrieval, and AI processing to occur directly in the user's
browser.
